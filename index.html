CLI & Google Colab

Two more ways to run the 1M17 + erlotinib example.

The CLI example was run with the packaged command. Your scores can differ.

python -m pip install anyonecandock
acd dock --receptor 1M17 --compound erlotinib \
  --name erlotinib --ph 7.4 --exhaustiveness 4 \
  --poses 5 --yes --output ./erlotinib_dock
Find erlotinib_scores.csv, erlotinib_out.pdbqt, and SDF structures in ./erlotinib_dock/.

Google Colab workflow ↗

  1. 0 Setup: run Install Conda Colab, Install Dependencies and Docking Engines, then Import Modules & Verify Tools. Follow any restart prompt.
  2. 1 Receptor: download 1M17 from RCSB, use the detected co-crystal ligand to center the 18 × 18 × 18 Å box.
  3. 2 Ligand: select text input, enter erlotinib, set output_name to erlotinib and target_pH to 7.4.
  4. 3 Dock: select VINA, docking_runs = 1, run_redock = false; keep the default exhaustiveness 16 and 10 poses.
  5. 4 Inspect: select a pose; review top-pose plots and ProLIF 2D interactions. Repeated runs produce box plots.
  6. 5 Download: package docking_results.zip; a Gemini Markdown report is included if generation succeeds.

Four engines: VINA, VINAXB, GNINA, and VINA_GPU (requires a GPU runtime; installs on demand).

Gemini: enable auto_gemini_interpretation in Section 4 for a written interpretation when Colab AI is available. Verify its claims against scores and plots.

Screenshot documents the notebook interface; this guide does not claim a completed Colab docking run.

Understanding results

Example Online run of 1M17 + erlotinib; your values may differ.

Download a selected pose (.sdf/.pdb), all poses (.pdbqt), scores (.csv), or the receptor (.pdb).
Docking scores do not prove experimental binding affinity.
The best-scored pose is not always the correct one. Inspect the other poses, and when a co-crystal ligand exists, redock it first: a pose within 2 Å RMSD shows that the setup can reproduce the crystal binding mode.
How to citeHengphasatporn K, Bunchuay T, Duan L, Shigeta Y. Anyone Can Dock: an online molecular docking tool for everyone. J Cheminform. 2026. doi:10.1186/s13321-026-01306-2
Please also cite AutoDock Vina (Eberhardt et al., 2021; Trott & Olson, 2010). Jobs run through the API or an AI assistant include METHODS_AND_CITATION.txt with a ready-to-paste Methods paragraph.

  1. กรอก 1M17 แล้วเตรียมตัวรับ คงการตั้งจุดศูนย์กลางจากลิแกนด์ร่วมผลึกและกล่อง 18 × 18 × 18 Å

CLI และ Google Colab

อีกสองวิธีสำหรับตัวอย่าง 1M17 + erlotinib

คำสั่ง CLI ด้านล่างเคยรันด้วยแพ็กเกจแล้ว คะแนนของคุณอาจต่างกัน

python -m pip install anyonecandock
acd dock --receptor 1M17 --compound erlotinib \
  --name erlotinib --ph 7.4 --exhaustiveness 4 \
  --poses 5 --yes --output ./erlotinib_dock
ดู erlotinib_scores.csv, erlotinib_out.pdbqt และโครงสร้าง SDF ใน ./erlotinib_dock/

ขั้นตอนใน Google Colab ↗

  1. 0 ตั้งค่า: รัน Install Conda Colab, Install Dependencies and Docking Engines แล้ว Import Modules & Verify Tools ตามลำดับ รีสตาร์ตรันไทม์หากระบบแจ้ง
  2. 1 ตัวรับ: ดาวน์โหลด 1M17 จาก RCSB แล้วใช้ลิแกนด์ร่วมผลึกที่ตรวจพบเป็นศูนย์กลางกล่อง 18 × 18 × 18 Å
  3. 2 ลิแกนด์: เลือกการป้อนแบบ text กรอก erlotinib ตั้ง output_name = erlotinib และ target_pH = 7.4
  4. 3 ด็อกกิง: เลือก VINA, docking_runs = 1, run_redock = false และคง exhaustiveness 16 กับ 10 ท่าจับตามค่าเริ่มต้น

  6. 5 ดาวน์โหลด: สร้าง docking_results.zip ซึ่งจะมีรายงาน Markdown ของ Gemini หากสร้างสำเร็จ

CLI と Google Colab

1M17 + erlotinib の例を別の 2 つの方法で実行します。

下のコマンドはパッケージ版 CLI で実行済みです。スコアは変わる場合があります。

python -m pip install anyonecandock
acd dock --receptor 1M17 --compound erlotinib \
  --name erlotinib --ph 7.4 --exhaustiveness 4 \
  --poses 5 --yes --output ./erlotinib_dock
./erlotinib_dock/ に erlotinib_scores.csv、erlotinib_out.pdbqt、SDF 構造が保存されます。

Google Colab の流れ ↗

  1. 0 セットアップ：Install Conda Colab、Install Dependencies and Docking Engines、Import Modules & Verify Tools を順に実行します。指示があればランタイムを再起動します。
  2. 1 受容体：RCSB から 1M17 を取得し、検出された共結晶リガンドで 18 × 18 × 18 Å のボックスを中心に置きます。
  3. 2 リガンド：text 入力で erlotinib を指定し、output_name = erlotinib、target_pH = 7.4 にします。
  4. 3 ドッキング：VINA、docking_runs = 1、run_redock = false を選び、既定の exhaustiveness 16 と 10 ポーズを使います。
  5. 4 確認：ポーズを選択し、上位ポーズのグラフと ProLIF の 2D 相互作用を確認します。反復実行では箱ひげ図が表示されます。
  6. 5 ダウンロード：docking_results.zip を作成します。Gemini の解釈が成功した場合は Markdown 報告も入ります。

4 つのエンジン：VINA、VINAXB、GNINA、VINA_GPU（GPU ランタイムが必要で、選択時にインストール）。

Gemini：第 4 部で auto_gemini_interpretation を有効にすると、Colab AI が利用可能な場合に文章で解釈します。スコアと図を照合してください。
